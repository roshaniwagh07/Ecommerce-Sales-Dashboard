# 📊 E-commerce Sales & Customer Insights Dashboard (Brazil – Olist Dataset)

## 🔍 Overview

This project presents an interactive Power BI dashboard built using the **Brazilian E-commerce Public Dataset by Olist**.
The dashboard provides insights into **sales performance, customer behavior, and delivery efficiency**, helping identify key business opportunities.

---

## 🎯 Objectives

* Analyze overall sales performance and trends
* Understand customer segmentation (New vs Repeat)
* Evaluate delivery performance and its impact on retention
* Identify top-performing product categories and regions

---

## 📈 Key Insights

* 💰 **Total Revenue:** 32M+
* 📦 **Total Orders:** 98K+
* 🚚 **On-time Delivery Rate:** 92%
* 🔁 **Repeat Customer Rate:** ~3%

### 🔍 Key Findings

- Majority of customers are new (~97%), indicating low retention  
- Repeat customers experience lower late delivery rates  
- Delivery performance appears to influence customer retention 

### ⭐ Business Insight:

Repeat customers experience **lower late delivery rates**, indicating that **delivery performance directly impacts customer retention**.

---

## 📊 Dashboard Features

* **Revenue Trend Analysis** (time-based performance)
* **Top 5 Product Categories by Revenue**
* **Geographical Sales Distribution (Brazil Map)**
* **Payment Method Analysis**
* **Customer Segmentation (New vs Repeat)**
* **Late Delivery Rate by Customer Segment**

---

## 🧠 Data Modeling & DAX

* Created calculated measures for:

  * Revenue, Orders, Repeat Rate
  * Late Delivery %
  * Customer Segmentation (based on order frequency)
* Implemented relationships across:

  * Orders, Customers, Payments, Reviews
* Optimized model using **clean relationships instead of complex DAX where possible**
